# Changelog

All notable changes to GainCheck are recorded here.

## [0.1.0] - Unreleased

- Added deterministic supplied-file measurements with byte/line counts and SHA-256 fingerprints.
- Added literal marker checks, explicit provenance, unknown outcomes, and stable JSON receipts.
- Added bounded manifest checks with aggregate exit codes for CI.
- Added an optional, read-only RTK recorded-estimate audit for standalone rollback-journal databases.
- Added synthetic demo fixtures and build-only cross-platform CI.

This release does not claim token savings, billing savings, semantic equivalence, universal agent coverage, or forensic filesystem isolation.
